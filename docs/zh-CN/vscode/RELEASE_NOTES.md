# VS Code 扩展 0.1.14（尚未发布）

> 译者版本说明：本文件的标题和版本条目是源文档中的历史记录，不是当前发布状态声明；alpha.21 对应的扩展版本为 0.1.16。以下完整保留源文档所列阶段。

更新以支持 Rust alpha.19：增加 `import`、十个明确的 CSV/TSV 读取器补全、代码片段和函数帮助，以及语法高亮。已有的 FITS 和输出调用现在可以通过 alpha.19 引擎用于编译执行。编辑器提示不能取代引擎对表格、模块或证据的严格检查。

## 前一阶段：0.1.13

更新以支持 Rust alpha.18 的首个统计功能阶段：为保持量纲的 `sum` 和 `mean` 增加补全、代码片段、函数帮助和高亮。执行这些函数需要 alpha.18 引擎。

## 前一阶段：0.1.12

更新以支持 Rust alpha.17。增加 18 个电学 `ee_` 函数、SI 电学单位补全与高亮、代码片段以及六轴量纲标签。仍包含化学词汇。函数语义由已安装的 Goblin++ 引擎定义。

## 前一阶段：0.1.11

更新以支持 Rust 0.1.0-alpha.16。为版本化化学注册表、摩尔质量、质量／物质的量、浓度、稀释、实用实验室单位、`R` 和 `m_u` 增加高亮、补全帮助和代码片段。

## 前一发布：0.1.10

更新以支持 Rust 0.1.0-alpha.15。为天文距离换算、向量代数、显式极坐标／球坐标换算、线速度、明确命名的伽利略速度叠加与共线相对论速度叠加，以及旋转运动辅助函数增加高亮和详细补全帮助。

## 前一发布：0.1.9

为显式区分度／弧度的三角函数、反函数、`atan2d`/`atan2r` 和 `deg2rad`/`rad2deg` 增加高亮、补全帮助和代码片段。无后缀三角函数名标记为已弃用、兼容弧度的别名；警告和执行语义由引擎负责。

## 前一发布：0.1.8

更新以支持 Rust 0.1.0-alpha.13。为具备量纲检查的科学数学内置函数增加高亮、补全帮助和代码片段，包括 `sqrt`、三角函数、对数、极值、舍入、`atan2` 和 `hypot`。

## 前一发布：0.1.7

更新以支持 Rust 0.1.0-alpha.12。为直接数组迭代、`break`、`continue`、短路 `and`/`or`/`not`、整数余数和 `parse_integer` 增加高亮、补全帮助和代码片段。运行时语义的权威仍是 Goblin++ 引擎。

## 前一发布：0.1.6

更新以支持 Rust 0.1.0-alpha.11。为显式过滤／加权的 FITS 汇总增加 `fits_select_stats` 高亮、补全帮助和代码片段。在经过审核的 VSIX 打包完成之前，这仅是编辑器源码。

## 前一发布：0.1.5

更新以支持 Rust 0.1.0-alpha.10。为经过检查的文本转数值和拆分／连接增加 `g_strings` 内置函数高亮、补全和代码片段。文本 `+` 和 `len(text)` 在引擎中可用；扩展仍仅提供建议。

## 前一发布：0.1.4

更新以支持 Rust 0.1.0-alpha.9。增加 `g_func` 和 `return` 高亮、补全帮助及函数代码片段。编辑器仍仅提供建议；运行时语义和保管判定由引擎负责。

## 前一发布：0.1.3

更新以支持 Rust 0.1.0-alpha.8。增加 `input()` 提示框、Run With Arguments（带参数运行），以及按值复制数组、`len` 和 `append` 的高亮／补全／代码片段。交互回答以明文运行证据保存；编辑器不会将其变为秘密。扩展仍是编辑器辅助；语法和保管判定由 CLI 负责。

## 前一发布：0.1.1

更新以支持 Goblin++ Rust 0.1.0-alpha.6。为 `if`、`else if`、`else`、`switch`、`case` 和 `default` 增加高亮、补全帮助和代码片段。编辑器仍仅提供建议：语法、分支语义和保管结果由 Rust CLI 决定。扩展标识不变，因此安装此 VSIX 会更新现有扩展。

## 前一发布：0.1.0

更新以支持 Goblin++ Rust 引擎 0.1.0-alpha.5。命令现在启动 `goblin++`，而不是 Python。提供新的显式编译运行命令。只读诊断能识别 Rust `goblin.check.v1` 响应和词法／解析器的 stderr 失败信息，而不会编造源码范围。

高亮、补全、代码片段和随包指南现在覆盖循环、布尔比较、FITS 导入、带审计的输出和可选 `GO_PARANOID`/`seal`。Icon View（图标视图）仍只影响视觉显示，并且现在忽略内联 Rust 代码块。原有扩展标识、符号和图标映射设置得以保留。`goblinpp.pythonPath` 已由 `goblinpp.executablePath` 替代。

扩展是编辑器辅助。它不随包提供引擎，不授权内联 Rust，不认证作者身份，也不声称通过预览就能证明科学正确性。
