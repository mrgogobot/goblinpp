# Python 0.0.7 到 Rust 的移植矩阵

参考产物：`goblinpp-v0.0.7.zip`，SHA-256 为 `898b7a710672f5f712bbe002f28af46bd0f98d96b02f2cce4aec014a11a4f500`。

“已实现”表示经过 Rust 测试。“待实现”表示在没有证据时拒绝宣称一致性。

> **译者说明：** 下表保留原文的 Alpha.19 历史状态，包括当时的编辑器版本和“工作树中已实现”等表述；这些不是 alpha.21 最新发布状态的断言。当前能力请结合 CLI 检查；alpha.19 及以后版本的原生 FITS／文件支持见 [DATA_MODULES_NATIVE.md](DATA_MODULES_NATIVE.md)。

## 升级关卡

在满足以下条件前，Rust 引擎不应取代 Python 0.0.7 成为稳定参考：

1. 完整规范性语法和语义语料在两个引擎上运行；有意的版本化扩展（包括文本 `+`）记录为明确例外，并单独测试；不接受未标明的偏离。
2. 回执、冻结、修订谱系和账本模式具有明确迁移规则。
3. 签名、恢复和旧证据接纳完成移植，并包含失败路径测试。
4. FITS 数值语义超出固定宽度 `specObj-dr16.fits` 关卡，扩展到压缩图像、特殊列、声明单位及来自多种归档的测试样本。
5. 在干净机器上的发布构建能重现测试结果和清单。
