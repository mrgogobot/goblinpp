# 统计基础 — alpha.18，第 1 步

`sum(values)` 返回总和。`mean(values)` 返回算术平均值。两者都仅接受一个非空数值数组，可用于解释执行和原生编译执行的程序，并且不会修改数组。

```goblin
GO_PARANOID
measurements = [10 m, 11 m, 12 m]
total = sum(measurements)
average = mean(measurements)
print("total = {total}")
print("average = {average}")
seal total
seal average
```

预期程序输出（位于运行证据摘要之前）：

```text
total = 33 m
average = 11 m
```

使用 `goblin++ examples/statistics_basics.gbl` 运行随包示例，或加上 `--compile` 运行其编译形式。日常使用不要求 `GO_PARANOID` 或 `seal`；它们现有的证据规则保持不变。

## 单位与输入规则

- 每个元素都必须是有限的数值物理量，且具有相同量纲。
- 兼容的单位拼写会规范化为 SI：`mean([1 km, 500 m])` 得到 `750 m`。
- 结果保留输入量纲，包括电流和复合单位。
- 支持单元素数组；**两个**函数都拒绝空数组。Goblin++ 不会为一个空和或没有观测值的平均数凭空指定量纲。
- 文本、布尔值和嵌套数组不是数值观测。绝不会暗中过滤、解析数值，或把它们视为零。
- 现有的数组限制、索引、切片和独立副本语义仍适用。
- 与其他内置函数一样，`sum` 和 `mean` 是保留的函数名／形参名。仍可使用同名普通变量；调用语法会调用内置函数。

以下示例会失败，而其运行证据仍可独立验证：

```goblin
x = mean([])
x = sum(["10", "11"])
x = mean([1 m, 1 s])
x = sum([1e308, 1e308])
```

## 浮点策略

共享运行时按源顺序使用补偿求和（Neumaier 算法）。例如，`sum([1e16, 1, -1e16])` 能恢复 `1`，而不是丢失小项。求和会拒绝非有限的中间总和、补偿量或最终结果：即使 `sum([1e308, 1e308, -1e308])` 也会失败，不会假定后续抵消能挽救已溢出的中间总和。

平均值计算先将每个值除以输入的最大绝对值，对缩放后的和进行补偿，再除以元素数，最后恢复尺度。因此，`mean([1e308, 1e308])` 得到 `1e308`，尽管 `sum(...)` 会失败。全零数组返回具有相应量纲的零。这是 `f64` 算术，不是精确算术：仍可能发生舍入，极小项在缩放时可能下溢，次正规数结果也可能舍入为零。补偿改善稳定性，但不能证明任意精度或测量准确度。
