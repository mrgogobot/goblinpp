# 用户自定义函数（`g_func`）

> **译者说明：** 本文保留原文关于原生编译尚不支持 FITS／输出内置函数的历史限制。alpha.19 及以后版本已增加相关支持，详见 [DATA_MODULES_NATIVE.md](DATA_MODULES_NATIVE.md)；实际能力请结合当前 CLI 检查。

`g_func` 在普通 Goblin++ 代码中定义可复用计算。声明位于顶层，但调用可出现在表达式中及其他函数中。声明可以位于首次使用之后。

```goblin
g_func mean_of_two(a, b) {
    total = a + b
    return total / 2
}

value = mean_of_two(2 kg, 4 kg)
print("mean = {value}")
seal value
```

`return expression` 会立即结束函数，即使它位于嵌套的 `if`、`switch`、`for` 或 `while` 中。没有隐式返回：执行到函数结尾会产生并保存 `G203` 失败。调用必须传入与声明数量完全相同的参数；重复或保留的函数名／参数名会被拒绝。最多允许 32 个参数和 16 个活动调用；后一限制约束意外递归。函数内仍适用现有的共享循环上限。

实参在调用方求值，并复制到一个新的局部变量环境。局部赋值不会改变调用方变量，数组也不共享底层存储。函数不能隐式读取调用方变量，应将它们作为参数传入。已注册常量、`argc`/`argv` 及内置函数仍可用。函数内的 `print` 和 `printf` 追加到运行的正常输出中，该输出会计算哈希。

函数内不允许 `GO_PARANOID`、`seal`、嵌套 `g_func` 声明和内联 Rust 块。调用方可封存返回值。解释器允许在函数内使用 FITS 和生成输出的内置函数，并保留通常的导入／输出证据。在这些内置函数的编译语义实现之前，原生编译器会拒绝程序中任何位置的此类函数，即使位于从未调用的函数内。源码、规范化程序、输出和封存值保留现有的冻结／运行／验证规则。
