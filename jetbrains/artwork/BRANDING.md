# Goblin++ branding in the JetBrains plugin

`goblinpp.png` is the official Goblin++ project logo supplied by Malin Hess for
this package. It was generated with GPT at Malin Hess's direction and selected
as project branding.

The logo is separate from the MIT-licensed plugin software. Inclusion in this
official Goblin++ plugin does not grant permission to use it as the branding of
another project or to imply an association with Goblin++. See the repository's
top-level `BRANDING.md` for the complete project statement.
