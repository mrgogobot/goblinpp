# Goblin++ project logo

The logo at `assets/goblinpp-logo.png` was generated with GPT at Malin Hess's
direction and selected as Goblin++ project branding. It is shown in the
repository README to identify this project.

documentation prose and diagrams. Neither of those project licenses grants
permission to use the logo as the branding of another project or to imply that
another project is officially associated with Goblin++. For other branding
uses, contact the project maintainer.

This does not change the licenses of the source code, examples, documentation,
or existing VS Code file icons.
